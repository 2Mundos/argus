# Validating Claude and Codex as executors

Status: **procedure only, not run.** The sandbox that built the layer split has no
live Claude or Codex credentials, so no executor-layer validation was recorded.
Until it is, Claude and Codex report `layers[executor].readiness.validated` as
`unknown` and are not routable as executors by difficulty ([engines](../specs/engines.spec.md),
[task difficulty](../specs/task-difficulty.spec.md)).

Same shape as the [Cursor fleet smoke](2026-10-18.cursor-fleet-smoke.ref.md):

1. Lease an account for the engine on a worker whose image has the CLI.
2. Run a real task through `argus-delegate` for that executor with a controlled
   nonce in the prompt; require exit 0 and the exact nonce in the native result.
3. Record the fact on the ledger row under `layers.executor.validated`
   (`{"ok": true, "detail": "...", "at": "<utc>"}`), not the flat `validated`,
   which belongs to the harness layer.
4. `GET /api/engines` must show the executor layer usable and the harness layer
   unchanged.

No secrets go into the ledger or the run record.
