Schema migrations: `0087_task_error_attempt.sql`, `0088_code_review_fix.sql`, `0089_remove_review_chains.sql`, `0090_forge_integrations.sql`, `0091_review_finding_verification.sql`. Argus applies them on start, after which
an older build refuses the database. Back up the database (or confirm
the Litestream replica is current) before upgrading; rolling back means
restoring that backup and running the previous image.
