## Upgrading

Schema migrations: `0080_integrations.sql`, `0081_task_integrations.sql`, `0082_integration_config_version.sql`, `0083_decisions_created_at.sql`, `0084_cursor_admin_key.sql`, `0085_execution_routes.sql`, `0086_task_execution_route.sql`. Argus applies them on start, after which
an older build refuses the database. Back up the database (or confirm
the Litestream replica is current) before upgrading; rolling back means
restoring that backup and running the previous image.
